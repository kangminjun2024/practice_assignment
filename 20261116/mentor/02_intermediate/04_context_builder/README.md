# 04 · Context 선택·예산

PPT **28~36장**, 실습 약 **25분**. 강사용: 정답이 완성된 코드입니다. 실제 모델 응답·평가는 자동으로 채우지 않습니다.

## 목표
직접 정한 ID로 지식을 골라 문맥을 만들고 출력 공간을 예약합니다.
