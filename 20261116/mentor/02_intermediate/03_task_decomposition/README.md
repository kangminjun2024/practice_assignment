# 03 · 작업 분해와 정보 부족

PPT **21~27장**, 실습 약 **30분**. 강사용: 정답이 완성된 코드입니다. 실제 모델 응답·평가는 자동으로 채우지 않습니다.

## 목표
명시된 사실 카드를 보고 근거의 유무를 판단합니다. 자유로운 문장을 자동 의미 분석하는 실습이 아닙니다.

## 편집할 파일
`analysis.py`
`# BEGIN/END` 블록의 골격을 완성하고 해당 NotImplementedError 줄을 지웁니다.
각 TODO는 요구·입력·완료 기준을 주석으로 함께 설명합니다.

| 블록 | 요구사항 |
|---|---|
| `D21-03-I01` | 질문이 요구하는 사실과, 제공 자료가 지원하는 사실을 구분하세요. |
| `D21-03-I02` | 하나라도 근거가 부족하면 수업의 정보 부족 상태를 선택하세요. |
| `D21-03-I03` | 정상·정보 부족의 판단과 최종 출력 지시를 저장하세요. |
| `D21-03-I04` | 위치와 기간을 함께 묻는 질문에서 빠진 사실을 확인하세요. |

## 실행 위치
터미널에서 **이 README가 있는 폴더**로 이동합니다. `python`은 선택한 가상환경입니다.
```powershell
python main.py
```
`python main.py`를 파일의 절대경로로 실행해도 데이터·출력은 이 폴더 기준입니다.
