# 강사 운영안

## 수업 전
선택한 Windows·VS Code·Python 환경에서 `tools/check_environment.py`를 실행합니다.
설치 여부·실행 Interpreter를 확인하고 미완성 mentee와 완성 mentor를 혼동하지 않습니다.
실제 ChatGPT 계정·네트워크·표시 모델·도구 조건을 확인합니다. 기본필수는 D 세트 6개와 H 세트 6개의 짧은 **실제 수동 응답**을 목표로 합니다.
응용·심화는 같은 조건의 반복을 한 번 더 관찰합니다. 시간이 부족하면 기본 6개를 우선하고 나머지는 미실행 상태로 남깁니다.
API 키는 내일 사용합니다. 오늘 스크립트는 LLM API나 DB를 자동 호출하지 않습니다.

## 교시 운영
01: 여섯 요구사항을 확인합니다. 무조건 긴 Prompt가 좋은 것이 아닙니다.
02: 예제901은 실제 문맥101~103과 다릅니다. 예제 변경 실험을 05의 근거 규칙 실험과 섞지 않습니다.
03: 사실 카드의 supported는 교사가 작성한 전제입니다. 코드가 일반 자연어 의미를 이해했다고 설명하지 않습니다.
04: 8192·4936은 가상 token 예산 연습입니다. 글자 수를 실제 token 수로 발표하지 않습니다.
05: D 질문으로 실제 첫 응답을 보존합니다. 자동 검사기는 다음 교시를 위한 제공 코드입니다. 가설·실패·미평가도 결과입니다.
06: 학생이 작성한 로컬 Schema/파서/규칙을 실행합니다. coursekit의 참조 구현만 돌려 완료한 것으로 평가하지 않습니다.
07: 작성한 샘플의 2·2·1·1 호출 수를 확인합니다. 모델 복구 성공률이 아닙니다.
08: 05의 frozen_bundle.json을 넘겨 H 3질문을 확인합니다. 이전 교시 미완성자는 제공 체크포인트를 쓰되 D 실험 개선으로 기록하지 않습니다.

## 05/08 기록 방식
1. prepare는 raw 없이 **계획**만 생성합니다.
2. 실제 응답을 record_manual.py로 등록합니다. 코드 블록이나 실패를 편집하지 않습니다.
3. review로 문법/구조/출처 결과를 확인합니다.
4. human_review.json을 실제 질문·주장·본문에 근거해 작성합니다.
5. 형식 오류만 한 번 수정 요청합니다. 첫 응답 점수는 고치지 않습니다.
6. 사람 평가하지 않은 항목은 null입니다. B가 이겨야 만점이 아닙니다.
