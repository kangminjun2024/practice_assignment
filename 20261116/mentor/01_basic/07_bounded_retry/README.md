# 07 · 실패 분류·최대 2회

PPT **56~63장**, 실습 약 **30분**. 강사용: 정답이 완성된 코드입니다. 실제 모델 응답·평가는 자동으로 채우지 않습니다.

## 목표
모델 대신 작성된 샘플로 최대 시도·중단 조건을 검증합니다.

## 편집할 파일
`main.py`
`# BEGIN/END` 블록의 골격을 완성하고 해당 NotImplementedError 줄을 지웁니다.
각 TODO는 요구·입력·완료 기준을 주석으로 함께 설명합니다.

| 블록 | 요구사항 |
|---|---|
| `D21-07-B01` | 허용한 형식 오류만 안전한 한 문장 요약으로 수정 요청을 만드세요. |
| `D21-07-B02` | 최초 1회+수정 1회까지만 반복하고 통과하지 못하면 None을 반환하세요. |
| `D21-07-B03` | 네 fixture 순서의 호출 수 2·2·1·1을 확인하고 기록하세요. |

## 실행 위치
터미널에서 **이 README가 있는 폴더**로 이동합니다. `python`은 선택한 가상환경입니다.
```powershell
python main.py
```
`python main.py`를 파일의 절대경로로 실행해도 데이터·출력은 이 폴더 기준입니다.
