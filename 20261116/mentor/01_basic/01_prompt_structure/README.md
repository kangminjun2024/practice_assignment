# 01 · Prompt 구조와 요구사항

PPT **7~13장**, 실습 약 **25분**. 강사용: 정답이 완성된 코드입니다. 실제 모델 응답·평가는 자동으로 채우지 않습니다.

## 목표
지식 답변의 요구사항을 여섯 칸으로 정하고 고정 규칙과 변수를 나눕니다.

## 편집할 파일
`main.py`
`# BEGIN/END` 블록의 골격을 완성하고 해당 NotImplementedError 줄을 지웁니다.
각 TODO는 요구·입력·완료 기준을 주석으로 함께 설명합니다.

| 블록 | 요구사항 |
|---|---|
| `D21-01-B01` | 역할·작업·입력·제약·실패·출력 여섯 칸을 완성하세요. |
| `D21-01-B02` | Template에 질문·직렬화한 지식·출력 계약을 대입하세요. |
| `D21-01-B03` | 요구사항과 Prompt 원문을 저장하고 기준 질문을 확인하세요. |

## 실행 위치
터미널에서 **이 README가 있는 폴더**로 이동합니다. `python`은 선택한 가상환경입니다.
```powershell
python main.py
```
`python main.py`를 파일의 절대경로로 실행해도 데이터·출력은 이 폴더 기준입니다.

## 산출물
`requirements.json`, `prompt.txt`. 예상 결과는 `expected/EXPECTED.md`와 대조합니다.
