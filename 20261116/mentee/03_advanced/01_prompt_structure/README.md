# 01 · Prompt 구조와 요구사항

PPT **7~13장**, 실습 약 **25분**. 수강생용: TODO가 있는 미완성 코드입니다.

## 목표
지식 답변의 요구사항을 여섯 칸으로 정하고 고정 규칙과 변수를 나눕니다.

## 편집할 파일
`prompt_builder.py`
`# BEGIN/END` 블록의 골격을 완성하고 해당 NotImplementedError 줄을 지웁니다.
각 TODO는 요구·입력·완료 기준을 주석으로 함께 설명합니다.

| 블록 | 요구사항 |
|---|---|
| `D21-01-A01` | 역할·작업·입력·제약·실패·출력 여섯 칸을 완성하세요. |
| `D21-01-A02` | 빈 질문과 필수 요구사항 누락을 먼저 거부하세요. |
| `D21-01-A03` | Template에 질문·직렬화한 지식·출력 계약을 대입하세요. |
| `D21-01-A04` | 요구사항과 Prompt 원문을 저장하고 기준 질문을 확인하세요. |
| `D21-01-A05` | 정상·정보 부족 두 질문에 같은 요구사항을 적용하고 충돌 지시를 고치세요. |
| `D21-01-A06` | 누락 변수와 빈 질문이 실패함을 검사하세요. |

## 실행 위치
터미널에서 **이 README가 있는 폴더**로 이동합니다. `python`은 선택한 가상환경입니다.
```powershell
python main.py
```
`python main.py`를 파일의 절대경로로 실행해도 데이터·출력은 이 폴더 기준입니다.
